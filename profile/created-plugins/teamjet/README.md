# TeamJet (DSH)

Страница-плагин для DeepSeek Harness: показывает заявки отеля из TeamJet прямо
в сайдбаре приложения.

## Состав

| Файл | Что это |
|---|---|
| `client.js` | панель: сайдбар-запись, счётчики, таблица, фильтры |
| `index.js` | пустой Host-вход (плагин клиентский) |
| `cordis.patch.yml` | вставка записи в дерево профиля |
| `locale/*.json` | заголовок и описание для Plugin Manager |
| `docs/DETAIL.md` | архитектура доступа к API, ограничения |

## Зависимость

Читает данные через локальный мост из репозитория `dsh-config`:

```powershell
node bridge\bridge.mjs
```

Логин и пароль TeamJet задаются в `bridge/bridge.config.json` (в git не попадает).
Без моста панель показывает инструкцию по запуску вместо списка заявок.
