# Заявки отеля (DSH)

Страница-плагин для DeepSeek Harness: показывает заявки из CRM отеля «Манжерок 5★»
прямо в сайдбаре приложения.

## Состав

| Файл | Что это |
|---|---|
| `client.js` | вся панель: сайдбар-запись, счётчики, таблица, фильтры |
| `index.js` | пустой Host-вход (плагин клиентский) |
| `cordis.patch.yml` | вставка записи в дерево профиля |
| `locale/*.json` | заголовок и описание для Plugin Manager |
| `docs/DETAIL.md` | подробности: архитектура доступа, ограничения |

## Зависимость

Читает данные через локальный мост из репозитория `dsh-config`:

```powershell
node bridge\bridge.mjs      # слушает 127.0.0.1:8878
```

Без моста панель показывает инструкцию по запуску вместо списка заявок.

## Адрес CRM

По умолчанию `https://mznh5.energycontract.ru` (задан в `bridge/bridge.config.json`,
создаётся при первом запуске моста). Адрес самой страницы «Открыть CRM» берётся
из константы в `client.js` — при переезде домена правьте оба места.
